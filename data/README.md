# Data

This project uses **no external datasets**. Every physical parameter (masses, thrust, specific impulse, inertia, drag, wind statistics) is a synthetic value chosen to be physically plausible for a generic small lander. All values are listed with units in [THEORY.md](../THEORY.md#3-model-equations). Public landing telemetry for real vehicles is not available, and the study compares how robust different controllers are rather than predicting the behaviour of a specific vehicle.
